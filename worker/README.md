# ИИ-редактор Prompt Atelier

Небольшой сервер на Cloudflare Workers. Сайт отправляет сюда бриф (идею, модель, стиль, файлы с тегами, черновик), сервер просит Claude составить полный промпт по базе знаний и возвращает EN, RU и список додуманных деталей. Ключ API хранится на сервере и не попадает в браузер.

## Что нужно
- аккаунт Cloudflare (бесплатный тариф подходит);
- ключ Anthropic API (console.anthropic.com), запросы платные.

## Запуск
```bash
cd worker
npm install
npx wrangler login
npx wrangler secret put ANTHROPIC_API_KEY
npx wrangler deploy
```
После `deploy` появится адрес вида `https://prompt-atelier.<аккаунт>.workers.dev`. Его нужно вставить на сайте: «Выдача» → «ИИ-редактор» → «Адрес ИИ-сервера».

В `wrangler.toml` в `ALLOWED_ORIGIN` указан адрес сайта на GitHub Pages: запросы с других сайтов браузер не пропустит. Если адрес сайта другой, поменяйте его там.

## Как устроено
- Модель: `claude-opus-5-5`, effort `medium`, ответ строго в JSON (`en`, `ru`, `assumptions`).
- В системный промпт идут база знаний без разделов 0, 16, 17 и карточки моделей; он кэшируется, поэтому повторные запросы дешевле.
- Включены серверные fallbacks (`fallbacks: "default"`): если модель откажется отвечать, запрос автоматически перезапускается на рекомендованной запасной модели.
- Перед открытием для всех стоит добавить ограничение частоты запросов (Cloudflare Rate Limiting) или простую капчу: иначе чужие запросы будут тратить ваш баланс.
