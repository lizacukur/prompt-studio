# Инструкция для ИИ-помощника (Claude, ChatGPT, Codex, Cursor и др.)

Проект **LIZER PROMPTER** — сайт, который по идее пользователя пишет промпт для видео-нейросетей (Gemini Omni, Kling 4.0 Omni, Seedance 2.0 / 2.5, Wan 3.0 Omni) в синтаксисе SYNTX. Владелец: Елизавета Удахина. Общение с владельцем — по-русски, просто, без жаргона.

## С чего начать
1. Прочитай `docs/PROJECT_LOG.md` — хронология всех решений и что дальше.
2. Потом `docs/ARCHITECTURE.md` (как устроено) и `docs/AI_SETUP.md` (сервер ИИ).
3. Правила промптов — `knowledge/` (это «мозг» проекта, его используют и сайт, и сервер).

## Где что лежит
- `knowledge/prompt_service_knowledge_base.md` — база знаний (разделы 1–23); `model_cards_syntx.md` — модели; `camera_library.md` — камеры, объективы, 46 движений.
- `site/` — сайт без сборки: `index.html`, `styles.css`, `models.js` (модели), `engine.js` (разбор идеи), `router.js` (раскладка текста по блокам), `camera.js` (камеры и движения), `ai.js` (кнопка ИИ), `voice.js` (голосовой ввод, только русский), `app.js` (сборка черновика и интерфейс).
- `api/` — сервер ИИ-редактора для Vercel: `prompt.js` вызывает DeepSeek (`deepseek-flash`, видит фото; `deepseek-v4-pro` — без фото), `_lib.js` собирает инструкцию из нужных разделов базы.
- `docs/DESIGN_SYSTEM.md` — цвета и шрифты (тёмный фон, сливочный текст, бордо и красный).
- `prototype.html` — весь сайт одним файлом (собирается из `site/`, в git не хранится).

## Где работает
- Сайт: https://lizacukur.github.io/prompt-studio/ (GitHub Pages, публикуется сам при push в `main` через `.github/workflows/pages.yml`).
- Копия сайта и сервер: https://prompt-studio-self.vercel.app (Vercel, обновляется сам при push). Проверка сервера: `/api/health`.
- Ключ DeepSeek хранится только в Vercel (`DEEPSEEK_API_KEY`), в репозитории ключей нет и быть не должно.

## Правила работы
- Не ломай то, что уже договорено: теги всегда `@image1`, `@video1`, `@audio1`; голосовой ввод только русский; ученикам не нужна регистрация; Puter и Claude для учеников не используются (страны России и Сирии не поддерживаются, Puter просит телефон).
- Новые правила промптов добавляй в `knowledge/`, а не только в код; увеличивай версию базы и пиши «Изменения» в её шапке.
- После изменений: проверь сайт в браузере, сделай коммит, push в `main`, допиши пункт в `docs/PROJECT_LOG.md`.
- Не вставляй личную почту владельца в коммиты: автор `Elizaveta Udakhina <lizacukur@users.noreply.github.com>`.
- Платные запуски DeepSeek (тесты кнопки ИИ) стоят доли цента — делай их только для проверки и предупреждай владельца.
