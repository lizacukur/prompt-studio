# Как работает Prompt Atelier

## Путь пользователя
1. **Нейросеть.** Выбор из пяти: Gemini Omni, Kling 4.0 Omni, Seedance 2.0, Seedance 2.5, Wan 3.0 Omni. От выбора зависят режимы, лимиты файлов, длительности, форматы и допустимые роли аудио.
2. **Режим.** Текст → видео, фото → видео, первый + последний кадр, референсы (Omni), правка видео, продление. Показываются только режимы выбранной модели.
3. **Идея.** Свободный текст, по желанию финальный кадр и реплика героя.
4. **Файлы.** Фото, видео, аудио. Каждый файл получает тег по типу и порядку загрузки (`@image1`, `@video1`, `@audio1`) и роль: внешность, одежда, предмет, локация, свет, стиль, первый/последний кадр, сториборд, исходник правки, камера и темп, голос, музыка, липсинк. Роль по умолчанию ставится по режиму, её можно сменить.
5. **Кадр и звук.** Длительность и формат из карточки модели, свет, камера, монтаж, музыка, переключатели звука, реализма и надписей.
6. **Результат справа.** Проверки, настройки для SYNTX отдельно от текста, порядок загрузки файлов, EN-промпт, RU-перевод, кнопки копирования.

## Как собирается промпт
Порядок блоков — из раздела 13 базы знаний (каркас видео):
`GOAL → REFERENCES → SCENE AND LIGHT → TIMELINE (или EDIT SCOPE) → AUDIO → CONTINUITY → CONSTRAINTS`

- Хронометраж делится на стадии по длительности: до 6 с — одна, до 10 с — две, до 15 с — три, больше — четыре (хук → развитие → кульминация → развязка). Интервалы покрывают весь ролик без дыр.
- Роль файла превращается в фразу «что взять и чего не переносить» (разделы 3, 4).
- Блок реализма Лизы (раздел 7) добавляется при включённом переключателе; при жёстком солнце и ночи из него убирается «мягкий рассеянный свет».
- Русская реплика остаётся русской в EN-промпте (раздел 10).
- Файлы сверх лимита модели не попадают в промпт и показываются предупреждением.

## Этапы
| Этап | Что | Статус |
| --- | --- | --- |
| 1 | База знаний 1.1 + карточки моделей SYNTX | готово, карточки ждут проверки в SYNTX |
| 2 | Прототип интерфейса, сборка промпта по правилам без ИИ | готово (`site/`) |
| 3 | ИИ-редактор: идея → бриф → полный промпт по базе знаний | следующий шаг |
| 4 | Анализ прикреплённых фото (что видно, свет, одежда) | после этапа 3 |
| 5 | Индексация, домен, аналитика | по решению владельца |

## Этап 3: как подключить ИИ
Сайт на GitHub Pages статический: ключ API в браузере хранить нельзя, его увидит любой посетитель. Два варианта:
- **Посредник (рекомендуется для общего доступа).** Бесплатный Cloudflare Worker или аналог хранит ключ, принимает бриф и возвращает промпт. Сайт остаётся на GitHub Pages. Нужны лимит запросов и защита от злоупотреблений.
- **Свой ключ пользователя.** Человек вставляет свой ключ в настройках, он хранится только в его браузере. Без затрат для владельца, но неудобно для широкой аудитории.

Что отправлять модели (раздел 15 базы, «token routing»): короткое ядро (раздел 1), бриф из формы в JSON, только нужные модули (видео: 4, 6, 8, 9; с человеком ещё 3 и 7; речь — 10; правка — 11), одну карточку модели, текущий промпт прототипа как черновик. Всю базу целиком в каждый запрос не отправлять.

## Индексация
Сейчас выключена: `<meta name="robots" content="noindex, nofollow">` в `site/index.html` и `Disallow: /` в `site/robots.txt`. Чтобы включить, убрать meta-тег и заменить правило на `Allow: /`.
