# Как работает Prompt Atelier

## Путь пользователя
1. **Нейросеть.** Выбор из пяти: Gemini Omni, Kling 4.0 Omni, Seedance 2.0, Seedance 2.5, Wan 3.0 Omni. От выбора зависят режимы, лимиты файлов, длительности, форматы и допустимые роли аудио.
2. **Режим.** Текст → видео, фото → видео, первый + последний кадр, референсы (Omni), правка видео, продление. Показываются только режимы выбранной модели.
3. **Идея.** Свободный текст, по желанию финальный кадр и реплика героя.
4. **Файлы.** Фото, видео, аудио. Каждый файл получает тег по типу и порядку загрузки (`@image1`, `@video1`, `@audio1`) и роль: внешность, одежда, предмет, локация, свет, стиль, первый/последний кадр, сториборд, исходник правки, камера и темп, голос, музыка, липсинк. Роль по умолчанию ставится по режиму, её можно сменить.
5. **Кадр и звук.** Длительность и формат из карточки модели, свет, камера, монтаж, музыка, переключатели звука, реализма и надписей.
6. **Результат справа.** Проверки, настройки для SYNTX отдельно от текста, порядок загрузки файлов, EN-промпт, RU-перевод, кнопки копирования.

## Как пользователь описывает идею
- **Свободно.** Одно поле, можно писать всё подряд. `site/router.js` режет текст на фразы и раскладывает их по блокам (раздел 21 базы): действие, герой и одежда, место, свет, камера, стиль, детали, звук, финал. «4К» и «гипер реализм» уходят в настройки и стиль, «в атмосфере игры престолов» — в описание мира без названия франшизы.
- **По пунктам.** Отдельные поля с подсказками, что писать в каждое. Для тех, кто хочет точный контроль.

## Что сервис понимает из идеи (без ИИ)
`site/engine.js` разбирает текст по словарю корней: место (тайга, пустыня, кафе, город…), сезон, время суток, погода, герой (человек, животное, существо, предмет), жанр (реклама, разговор в камеру, динамика, эпик…). Чего нет в тексте — достраивается по связям из раздела 19 базы: Сибирь → зима → снегопад → низкое зимнее солнце → пар от дыхания и следы в снегу. Справа над промптом видно, что понято, а пунктиром — что додумано.

Стиль «Реализм» подбирает съёмку под сцену (кино, репортаж Canon, телевик для природы, плёнка Kodak, смартфон, предметка), объектив, диафрагму и фокус. Стиль «Мультфильм» полностью меняет камеру, стилистику, фактуры и запреты под выбранный вид анимации (раздел 18).

Ограничение офлайн-режима: само действие остаётся словами пользователя по-русски, а словарь узнаёт только то, что в нём есть. Это решает ИИ-редактор.

## Как собирается промпт
Порядок блоков — из раздела 13 базы знаний (каркас видео):
`GOAL → SUBJECT → REFERENCES → SCENE → LIGHT → CAMERA → STYLE → DETAIL → TIMELINE (или EDIT SCOPE) → AUDIO → CONTINUITY → CONSTRAINTS`

- Хронометраж делится на стадии по длительности: до 6 с — одна, до 10 с — две, до 15 с — три, больше — четыре (хук → развитие → кульминация → развязка). Интервалы покрывают весь ролик без дыр.
- Роль файла превращается в фразу «что взять и чего не переносить» (разделы 3, 4).
- Блок реализма Лизы (раздел 7) добавляется при включённом переключателе; при жёстком солнце и ночи из него убирается «мягкий рассеянный свет».
- Русская реплика остаётся русской в EN-промпте (раздел 10).
- Файлы сверх лимита модели не попадают в промпт и показываются предупреждением.

## Этапы
| Этап | Что | Статус |
| --- | --- | --- |
| 1 | База знаний 1.1 + карточки моделей SYNTX | готово, карточки ждут проверки в SYNTX |
| 2 | Прототип интерфейса, сборка промпта по правилам без ИИ | готово (`site/`) |
| 2.1 | Разбор идеи, реализм / мультфильм, камера и объектив, достраивание сцены | готово |
| 2.2 | Раскладка свободного текста по блокам, режим «по пунктам», камера по строкам | готово |
| 3 | ИИ-редактор: идея → бриф → полный промпт по базе знаний | отложен; код сервера лежит в `worker/`, на сайт не выведен |
| 4 | Анализ прикреплённых фото (что видно, свет, одежда) | после этапа 3 |
| 5 | Индексация, домен, аналитика | по решению владельца |

## Этап 3: ИИ-редактор (отложен)
Кнопка на сайте пока убрана, чтобы не путать пользователей. Код сервера сохранён.

Сайт на GitHub Pages статический: ключ API в браузере хранить нельзя, его увидит любой посетитель. Поэтому ключ живёт на небольшом сервере `worker/` (Cloudflare Workers), сайт отправляет туда бриф. Как развернуть — `worker/README.md`.

Что уходит модели: бриф из формы в JSON (модель, режим, стиль, файлы с тегами и ролями, настройки, что понято из идеи) и черновик офлайн-сборки. В системный промпт — база без разделов 0, 16, 17 и карточки моделей. Он одинаковый для всех запросов и кэшируется, поэтому вместо выборки разделов из раздела 15 передаётся целиком: так дешевле и стабильнее.

## Индексация
Сейчас выключена: `<meta name="robots" content="noindex, nofollow">` в `site/index.html` и `Disallow: /` в `site/robots.txt`. Чтобы включить, убрать meta-тег и заменить правило на `Allow: /`.
