# Как работает ИИ-редактор Claude (через Puter)

## Коротко
- Ключей, серверов и оплаты от владельца сайта не нужно.
- Каждый посетитель один раз входит в бесплатный аккаунт Puter. Запросы к Claude идут из его бесплатной месячной квоты.
- Claude официально доступен только в странах из списка Anthropic: https://www.anthropic.com/supported-countries. Например, Израиль — да, Россия и Сирия — нет. Для остальных стран на сайте остаётся черновик по правилам, он работает везде.

## Шаги для владельца (один раз)
1. Включить сайт: https://github.com/lizacukur/prompt-studio/settings/pages → **Build and deployment** → **Source: GitHub Actions**.
2. Дождаться публикации (1–2 минуты) и открыть https://lizacukur.github.io/prompt-studio/
3. Всё. Больше ничего подключать не нужно.

## Шаги для пользователя
1. Описать идею слева: свободно или по пунктам.
2. Внизу, в блоке «ИИ-редактор Claude», выбрать модель:
   - **Sonnet 5.5** — быстро, подходит для большинства идей;
   - **Opus 5.5** — сложные сцены, но быстрее расходует квоту.
3. Нажать **«Написать промпт с Claude»**.
4. Откроется окно Puter. Войти или создать бесплатный аккаунт. Если окно не появилось, разрешить всплывающие окна для сайта.
5. Справа промпт появляется по мере написания. Готовый текст можно скопировать.
6. Если после ответа что-то поменять слева, сервис предупредит: нажмите кнопку ещё раз, чтобы Claude переписал промпт.

## Что уходит в Claude
- Бриф из формы: модель, режим, стиль, идея, настройки, файлы — только имена, теги и роли. Сами фото и видео не отправляются.
- Черновик по правилам.
- Нужные разделы базы знаний, карточка выбранной модели и библиотека камер (около 50 000 знаков на запрос).

## Если не работает
- «Puter не загрузился» — нет доступа к js.puter.com: проверить интернет и обновить страницу.
- «Вход в Puter отменён» — окно входа закрыли, нажать кнопку ещё раз.
- Кончилась квота — Puter сам предложит пополнить. Дальше можно пользоваться черновиком по правилам.
- Из файла `prototype.html` на компьютере Claude не работает: Puter требует настоящий адрес сайта.
