# ИИ-редактор: DeepSeek на своём сервере (Vercel)

**Подключено 10.11.2026.** Сервер: https://prompt-studio-self.vercel.app (проверка: `/api/health`). Сайт: https://lizacukur.github.io/prompt-studio/ и копия на Vercel. Первый промпт (BMW, режим «Быстро») написан за 39 секунд.

## Как это устроено
- Ученики ничего не регистрируют: нажимают «Написать промпт с ИИ» и получают результат.
- Сайт отправляет бриф на сервер владельца (папка `api/` в репозитории). Сервер добавляет нужные разделы базы знаний и спрашивает DeepSeek. Ключ DeepSeek хранится только на сервере.
- Платит владелец, но очень мало: DeepSeek работает по предоплате, больше пополненного баланса потратить нельзя.
- Защита от чужих: сервер принимает запросы только с сайта владельца и не больше 30 запросов в день с одного адреса.

## Шаг 1. DeepSeek: аккаунт, баланс, ключ (≈ 5 минут)
1. Открой https://platform.deepseek.com и зарегистрируйся по почте или через Google.
2. Слева **Top up** → пополни баланс. Минимум около $5. Принимают банковскую карту и PayPal. Российские карты не проходят — нужна иностранная карта или PayPal.
3. Слева **API keys** → **Create new API key** → назови, например, `prompt-studio` → **Create**.
4. Скопируй ключ (начинается с `sk-`). **Его показывают один раз.** Сохрани в заметки и никому не отправляй, в чат тоже не вставляй.

## Шаг 2. Vercel: подключить репозиторий (≈ 5 минут)
1. Открой https://vercel.com/signup → **Continue with GitHub** → войди как **lizacukur**. Тариф **Hobby** (бесплатный).
2. На главной странице Vercel: **Add New… → Project**.
3. В списке репозиториев найди **prompt-studio** → **Import**. Если его нет — нажми **Adjust GitHub App Permissions** и дай Vercel доступ к этому репозиторию.
4. На экране настройки:
   - **Framework Preset:** Other;
   - **Root Directory:** оставить как есть (`./`);
   - **Build and Output Settings:** не трогать, всё задано в файле `vercel.json`;
   - **Environment Variables:** Key = `DEEPSEEK_API_KEY`, Value = ключ из шага 1 → **Add**.
5. Нажми **Deploy** и подожди 1–2 минуты.
6. Появится адрес вида `https://prompt-studio-xxxx.vercel.app` — скопируй его.

## Шаг 3. Сообщить адрес
Пришли адрес из шага 2 в чат (сам адрес, без ключа). Я пропишу его в сайт на GitHub Pages, и кнопка заработает и там.

Сайт заработает и по адресу Vercel. Это вторая копия, где кнопка ИИ работает сразу. Если у кого-то не открывается github.io, можно давать ссылку на vercel.app.

## Настройки (необязательно)
В Vercel → проект → **Settings → Environment Variables**:
- `DAILY_LIMIT_PER_IP` — сколько запросов в день с одного адреса (по умолчанию 30);
- `ALLOWED_ORIGINS` — с каких сайтов принимать запросы (по умолчанию `https://lizacukur.github.io`).

После изменения переменных: **Deployments → … → Redeploy**.

## Фото
- Модель `deepseek-flash` видит изображения (JPEG, PNG, GIF, WebP). У `deepseek-v4-pro` распознавания нет, поэтому с фото всегда работает режим «Быстро».
- Сайт уменьшает каждое фото до 1024 px по длинной стороне и отправляет до 6 фото вместе с тегом и ролью.
- Сервер добавляет в инструкцию правила по ролям (разделы 3, 4, 6 базы). Для роли «Внешность героя» ИИ не описывает черты лица: внешность берётся из фото по тегу.
- В ответе есть блок «На фото»: что ИИ увидел на каждом фото и куда это вставил.
- Галочка «Показывать фото ИИ-редактору» рядом с файлами: если её снять, фото не уходят, а ИИ знает только теги и роли. Видео и аудио не отправляются.
- DeepSeek — китайская компания. Если ученики прикрепляют свои лица, предупреди их об этом или попроси снимать галочку.

## Сколько это стоит
Один промпт — около 50 000 знаков базы знаний плюс бриф на входе и 3–6 тысяч знаков на выходе. По найденным ценам DeepSeek V4 Flash это доли цента за промпт; повторяющаяся часть (база знаний) кэшируется и стоит ещё дешевле. Режим Pro дороже в несколько раз. Точный расход видно в DeepSeek → **Usage**. Цены DeepSeek меняются, сверяй на https://api-docs.deepseek.com/quick_start/pricing.

## Если что-то не работает
- «ИИ-редактор ещё не подключён» — адрес сервера не прописан в сайт (шаг 3).
- «На сервере не задан ключ» — нет переменной `DEEPSEEK_API_KEY` в Vercel, или после её добавления не сделан Redeploy.
- «Неверный ключ DeepSeek» — ключ скопирован с ошибкой: создай новый и замени.
- «На балансе DeepSeek закончились деньги» — пополнить баланс.
- «Сервер недоступен» — у ученика не открывается vercel.app: напиши страну и провайдера.
- «Ответ оборвался» — модель не уложилась в лимит. Нажми ещё раз. Время на запрос — до 300 секунд (бесплатный тариф Vercel с Fluid Compute), лимит ответа — 32 000 токенов вместе с размышлениями модели.
