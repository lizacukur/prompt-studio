# Журнал проекта Prompt Atelier
Хронология решений по чату с Claude, 08.11.2026. Владелец: Елизавета Удахина.

## Идея
Сайт для общего доступа на GitHub Pages, без своего домена. Слева человек описывает идею, выбирает нейросеть и прикрепляет фото, видео или аудио (в пределах возможностей модели). Справа получает готовый промпт по базе знаний Лизы.
- Модели: Gemini Omni («Veo Omni»), Kling 4.0 Omni, Seedance 2.0, Seedance 2.5 (все режимы), Wan 3.0 Omni. Другие не добавлять.
- Синтаксис — как в SYNTX: теги `@image1`, `@video1`, `@audio1`.
- Дизайн: тёмный фон, сливочно-бежевый текст, бордо и красный.
- Индексация пока выключена, позже желательно включить.

## Этапы и решения
1. **База знаний 1.1.** Добавлены правила тегов SYNTX (раздел 12.1) и карточки пяти моделей (`knowledge/model_cards_syntx.md`). Сайты SYNTX, Kling и Google сеть сессии напрямую не открыла, поэтому данные собраны поиском. Все лимиты помечены «проверить в SYNTX».
2. **Прототип 0.1.** Интерфейс с выбором модели, режима, файлов, длительности, формата; справа — настройки, порядок загрузки файлов и промпт EN + RU. Сборка по шаблону без ИИ.
3. **Замечание Лизы:** промпт почти не меняется от идеи. Нужно детализировать и додумывать (Сибирь → зима), прописывать камеру, объектив, фон, макро-детали; реализм и мультфильм — полностью разные промпты.
   - Прототип 0.2: разбор идеи (место, сезон, время, погода, герой, жанр), достраивание сцены, переключатель «Реализм / Мультфильм» с пятью видами анимации, подбор камеры и объектива.
   - База 1.2: разделы 18 (стиль), 19 (достраивание сцены), 20 (форма промпта по моделям).
   - Написан ИИ-редактор на Cloudflare Workers с Claude (`worker/`).
4. **Замечание Лизы:** свободный текст попадает не туда («4К» — в начало промпта); ИИ-редактор путает людей — убрать.
   - Прототип 0.3: раскладка свободного текста по блокам по частям предложения; режим «По пунктам» с подсказками; «4К» уходит в настройки; отсылки к франшизам превращаются в описание мира; камера расписана по строкам. Кнопка ИИ-редактора убрана, код сервера сохранён.
   - База 1.3: раздел 21 (раскладка текста).
5. **Запрос Лизы:** каталог камер для реализма, DV-камера 2000-х для атмосферности, все движения с aicameramovements.com, похожие базы на GitHub.
   - `knowledge/camera_library.md`: около 25 камер и форматов, объективы, 46 движений с формулой Movement / Speed / Framing / End, логика выбора, уроки о типичных ошибках моделей (по Rylaispirit/cinematic-video-prompt-skill, MIT).
   - Прототип 0.4: подбор камеры и одного из 46 движений по идее; формат сильнее жанра.
   - База 1.4: раздел 22.
   - В окружении Default разрешён доступ к aicameramovements.com.
6. **Вывод на примере BMW** («переворачивается на 150 км/ч на 360° и едет дальше»): правилами не решить перевод (марки, сленг), механику события и хронометраж под конкретное действие. Нужна нейросеть, а база знаний остаётся её инструкцией.
7. **Выбор нейросети без своих ключей.** Варианты:
   - Cloudflare Workers AI — бесплатный дневной лимит, открытые модели;
   - Puter.js — платит пользователь из бесплатной квоты своего аккаунта, доступен Claude;
   - Gemini с бесплатным ключом;
   - встроенный ИИ Chrome.

   По качеству рекомендован **Claude (Sonnet по умолчанию, Opus для сложных сцен) через Puter.js**, второй вариант — Gemini. Решение о подключении ждёт подтверждения.

8. **Решение: Puter.js + Claude.** Проверено: Claude официально доступен не во всех странах (Израиль — да, Россия и Сирия — нет). Сделана кнопка «Написать промпт с Claude» (Sonnet 5.5 / Opus 5.5) с честной пометкой о странах; для остальных — черновик по правилам. Проект перенесён в репозиторий lizacukur/prompt-studio.
