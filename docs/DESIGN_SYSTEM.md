# Дизайн-система Prompt Atelier

Направление: тёмная «монтажная» или кинозал после сеанса. Почти чёрный тёплый фон, сливочный текст, бордо как подложка выделения и красный как цвет действия.

## Цвет
| Токен | Значение | Где |
| --- | --- | --- |
| `--bg` | `#0E0B0B` | фон страницы |
| `--surface` | `#161112` | панели, карточки |
| `--surface-2` | `#1E1718` | поля ввода, плитки моделей |
| `--line` | `#352829` | границы и разделители |
| `--cream` | `#EDE3D1` | основной текст |
| `--cream-dim` | `#A8998A` | подписи, второстепенный текст |
| `--wine` | `#6B1A25` | бордо: выбранный режим, бейджи, градиенты шапок |
| `--red` | `#B8323F` | главная кнопка, выбранная модель, фокус |
| `--red-hi` | `#D24B57` | теги `@image1` в тексте, наведение |
| `--ok` / `--warn` | `#8FA88A` / `#D9A55B` | только для проверок, не как акцент |

Правило: красного на экране мало — одна главная кнопка, выбранные элементы и теги. Бордо — для фона, не для текста.

## Шрифты
- **Cormorant Garamond** — заголовки и логотип, с курсивом в знаке «P». Только крупно.
- **Manrope** — интерфейс и текст.
- **JetBrains Mono** — промпты, теги, счётчики, бейджи.
Все три поддерживают кириллицу и подключаются из Google Fonts.

## Размеры
- Радиусы: 6 / 10 / 16 px (поле / плитка / карточка).
- Шрифт интерфейса 15 px, подписи 12.5 px, промпт 13.5 px моно, заголовок результата 40 px.
- Сетка: левая колонка 340–440 px, правая резиновая; до 900 px колонки складываются в одну.

## Компоненты
- **Плитка модели**: имя, провайдер, чипы «фото N / видео N / аудио N»; недоступный тип зачёркнут.
- **Чип режима**: круглый, выбранный — бордо с красной границей.
- **Файл**: превью 44 px, тег красным моно, имя файла, выбор роли, кнопки «выше» и «удалить».
- **Проверка**: полоса слева — зелёная (готово), янтарная (внимание), бордо (сведения).
- **Карточка промпта**: шапка с бейджем языка, счётчиком символов и кнопкой «Копировать»; текст моно, заголовки блоков приглушены, теги красные.
